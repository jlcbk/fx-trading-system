## 1. 经济机制

对商品出口国（主焦点 **CAD/USD** 与油价），油价冲击改变贸易条件与风险溢价，汇率在**极短窗口**内重新定价。关键经验结论是**频率依赖**：月度/季度伪样本外几乎看不到稳定关系；**日度**上，同期实现油价变动对名义汇率变动有稳健 OOS 关系。滞后油价的预测力更短暂，且依赖时变相对表现检验。机制是短期宏观/金融联动，不是慢速 carry/value 的替代。与 Chen–Rogoff–Rossi 等“汇率预测商品价格”方向对照：本文强调**反向**（商品→汇率）且强调高频。

## 2. 精确公式

```text
# 主 OOS 规格（同期实现基本面 / “ex-post” 预测评估）Eq.(1)
Δs_t = α + β Δp_t + u_t
# Δs_t = log 名义汇率一阶差分（CAD per USD 或文中定义）
# Δp_t = log 油价一阶差分
# 基准: 随机游走（通常无漂移）Δs_t = u_t

# 真正 ex-ante 滞后规格（稳健）
Δs_t = α + β Δp_{t-1} + u_t
# 滞后预测力更弱/更依赖时变检验

# 评价
# - 滚动/扩展窗估计；Clark–West 等 OOS 统计
# - 允许相对表现时变（波动窗口）
# - 对照: 利率等传统基本面在同日度设定下不稳健
# - 频率: 日度显著；月度弱；季度无

# 扩展
# 其他商品货币 + 对应商品价格（国别商品出口）
# 控制美元因素、宏观新闻冲击
```

**重要：** 同期 \(\Delta p_t\) 规格回答“给定油价路径的解释/同步预测能力”，**不是**可交易的严格因果信号；交易实现至少要用滞后或可交易预期。

## 4. 成本与可实现性

- 原文：预测能力，非完整执行合同
- 迁移破坏点：
  1. 日度信号 + 零售点差可能吞没短记忆 alpha
  2. 同期油价不可作为无摩擦交易信号
  3. 与项目慢周期（21/63 日）horizon **错配**
- midquote ≠ net：即使 OOS R² 显著也不等于净 PnL

## 5. 识别与稳健性

- 主结果：日度同期油价→CAD 稳健；月/季 OOS 崩溃
- 非美元伪影；控制新闻后仍在
- 滞后油价需时变表现才显著
- 失败：把日度相关当月度因子；把同期回归当策略

## 9. 精读问题（给最强模型）
