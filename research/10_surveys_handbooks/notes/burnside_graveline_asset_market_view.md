## 1. 经济机制

文献中流行的 **asset market view of exchange rates**（Brandt–Cochrane–Santa-Clara 等）写为：

> 若资产市场完全，则实际汇率的对数变动 = 外国代理人 log IMRS − 本国代理人 log IMRS。

该式常被用来断言：汇率波动反映两国代理人对**资产风险补偿**的差异。

本文核心批判：

1. 无摩擦交易的资产（含货币）的**相对收益**，只能识别代理人 IMRS 的**共同成分** \(M^\eta\)，不能识别“差异成分”。  
2. 当 asset-market-view 等式成立时，两国代理人对同一组相对资产收益 \(R^\eta\) 的风险补偿**相同**；IMRS 之差只来自**计价单位**——不同消费篮和/或一篮子内商品相对价格（货物市场摩擦或偏好差异）。  
3. 因此：仅凭资产收益、汇率与**加总消费**，**无法区分**“风险完美分担但偏好/货物摩擦不同”与“风险未完美分担”。  
4. 正面含义：要对汇率作结构性解释，必须把**货物市场与分项消费偏好**写清楚，而不是只写完全资产市场 + 加总 IMRS。

对量化研究的直接含义：  
不能从“汇率很波动 ⇒ 两国风险价格差很大 ⇒ 可交易 carry/风险因子有巨大国际风险溢价”这条捷径推出策略；溢价识别仍需可交易支付与 SDF 的可检验矩条件（并面对 Burnside 系列经验文中的因子失败结果）。

## 2. 精确公式

```text
# 无摩擦交易资产集合；选一资产组合 η 为 numeraire
# 相对收益向量 R^η_t（对本位组合归一）满足 R^η · η = 1

# 相对收益的 SDF（严格正）
1 = E[ M^η_t * R^η_t ]

# 本国/外国消费篮价格（以同一 numeraire 计价）
P_d,t , P_f,t
e_t = P_f,t / P_d,t          # 实际汇率：外国篮 / 本国篮
X_t = e_t / e_{t-1}
Π_d,t = P_d,t / P_d,t-1
Π_f,t = P_f,t / P_f,t-1
# ⇒ X_t = Π_f,t / Π_d,t

# 以消费篮计价的资产收益
R_t  = Π_d,t^{-1} R^η_t
R*_t = Π_f,t^{-1} R^η_t

# 计价变换：若 M^η 定价 R^η，则
# M = M^η Π_d 定价 R；M* = M^η Π_f 定价 R*
# 从而恒有“换 numeraire 恒等式”：
ln X_t = ln(M* 的某种形式) - ln(M 的某种形式)
# 但这里的差分来自 Π，不一定是“风险价格差”

# Asset market view（当 IMRS 恰好等于上述 SDF 时）：
ln X_t = ln IMRS*_t - ln IMRS_t
# 展开后共同 M^η 消去，剩下消费篮单位差：
ln X_t = ln Π_f,t - ln Π_d,t

# 关键：无套利 + 资产可无摩擦跨国交易
# 完全市场 ⇒ 存在对 R^η 可测的定价核；但不自动给出“差异化风险补偿”
```

文中后续用可贸易/不可贸易品、完全市场例子说明：相同偏好 + 货物摩擦时，汇率波动度量风险未分担程度；但**仅资产数据**无法把该结构与“偏好异质 + 完美分担”分开。

- 无策略。

- 零售路径仍只认可交易 \(z_{t+1}\) 与成本合同。

## 5. 识别与稳健性

- 批判对象：把 Eq.(1) 读成“汇率=风险补偿差”。  
- 保留：完全市场 + 明确货物结构时，汇率仍有福利/分担解释。  
- 失败模式：用加总消费增长 + 汇率波动反推可交易货币风险溢价并进入因子搜索。
